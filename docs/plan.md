# 계획과 확정된 결정

## 확정된 결정 (2026-10-21, 사용자가 이 대화에서 직접 답함)
1. **전환 시점과 목표:** 지금 CARLA로 전환한다. 화물을 배달하는 경로를 처음부터 끝까지 가는 데 필요한 **거의 모든 기능**이 CARLA에서 동작한다고 판단되면 그때 ETS2로 넘어온다. ETS2의 가상 컨트롤러 등 기존 도구는 그대로 둔다. (ETS2 복귀는 선택으로 둔다 — 제안이며 사용자가 따로 정한 것은 아님.)
2. **기능 순서(추천안 선택):** ① 차선 유지와 경로 명령(회전) → ② 속도 제어(앞차 따라가기, ACC) → ③ 신호 정지 → ④ 보행자·돌발 상황.
3. **CARLA 버전:** 안정적인 버전 — 공식 문서가 소개하는 **0.9.15**.
4. **코드 위치:** 새 폴더, 새 git, 새 GitHub 저장소(`CARLAUTOPILOT`, 비공개)의 별도 프로젝트.
5. **작업 장소:** 코드 작성과 컴퓨터(GPU)가 필요 없는 일은 다른 컴퓨터에서, 프로그램을 실제로 돌리는 것은 집 데스크톱(RTX 4070 SUPER)에서 한다.
6. **시간:** 평일 하루 4시간, 주 약 20시간.
7. **기존 코드 사용:** ETS2 프로젝트의 코드는 쓸 만하다고 판단되면 가져와도 된다. 새 프로젝트에 ETS2 데이터셋은 넣지 않는다(비상업적 연구용).
8. **원격 접속:** 집 데스크톱 원격 접속은 아직 설정되어 있지 않고, 필요하면 설정한다.

## 아직 확정되지 않은 것
- **"자율주행이 가능하다"의 통과 기준:** 정해진 시나리오 세트(직진, 좌우회전, 앞차 따라가기, 신호 정지)에서 경로 완주율과 충돌·신호위반 횟수로 판단하는 것을 제안했다. 구체적인 수치는 첫 결과를 본 뒤 사용자와 정한다.
- **배달 경로에 필요한 기능의 범위:** 고속도로, 회전교차로, 차선 변경, 목적지 정차 등을 어디까지 넣을지.
- **ETS2로 돌아갈지 여부와 시점.**

## 기능 체크리스트 (초안, 제안이며 확정 아님)
각 항목은 통과 기준을 정한 뒤에 시작한다.

| 단계 | 기능 | 통과 기준 |
|---|---|---|
| 0 | 환경: CARLA 서버 실행, 카메라 영상 저장, 데이터 자동 수집 | 미정 |
| A | 차선 유지, 경로 명령(직진·좌·우) | 미정 |
| B | 속도 제어, 앞차 따라가기(ACC) | 미정 |
| C | 신호 정지 | 미정 |
| D | 보행자, 돌발 상황 | 미정 |
| E | 긴 경로를 처음부터 끝까지 주행(배달 시나리오) | 미정 |
| F | (선택) ETS2 이식 | 미정 |

## 일정 어림 (가정, 확정 아님)
- 지금부터 2027년 여름까지 약 36주, 주 20시간이면 700시간 안팎이다. 학기 중 수업과 시험으로 줄어들 수 있어 여유를 둔다.
- 2026년 말까지: 환경 구축, 데이터 수집, 기본 조향 모델.
- 2027년 상반기: 경로 명령, 속도 제어, 신호 정지, 평가 틀.
- 2027년 여름: 핵심 기능 마무리와 정리. 이후 포트폴리오 작성(졸업 예정 2028년 2월).
- 첫 2주 안에 "CARLA 서버 실행, 영상 저장, 자동 데이터 수집"이 되는지 확인하고, 막히면 방향을 다시 판단한다.

## 확인이 필요한 사실 (미확인)
- 공식 문서(확인함): Windows 10·11 또는 Ubuntu 20.04·22.04, VRAM 8GB 이상 권장(2070급 이상), 디스크 약 20GB, 포트 2000과 2001, Python 3.7~3.12, pip 20.3 이상, 문서가 소개하는 최신 버전 0.9.15.
- 제가 아는 지식이라 설치 단계에서 공식 문서로 확인할 것: 기본 자동 주행(Traffic Manager autopilot)으로 전문가 데이터를 자동 수집하는 방법, 동기 모드와 시나리오 실행기로 같은 시나리오를 반복 실행하는 방법.
- 이전 컴퓨터의 Python이 3.14라서 CARLA용 Python 3.12 가상환경을 따로 만들어야 한다.
- CARLA의 기본 자동 주행 데이터는 사람보다 깔끔해서 학습 성능이 과대평가될 수 있다. 결과에 이 한계를 명시한다.
