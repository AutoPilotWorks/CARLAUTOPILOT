### 4-1. 카메라에 트럭 차체가 찍힘 (v1.8a/b 붕괴)
- 운전석 카메라 x=3.5가 차체 앞면(약 3.97 m)보다 안쪽에 있었습니다.
- 그래서 옆으로 옮기거나 회전한 학습 이미지에 와이퍼, 사이드미러, 차체가 찍혔습니다. 모델은 이것으로 조향 정답을 맞혔습니다.
- 다른 후보는 실험으로 배제했습니다.

  | 배제 실험 | 완주 |
  |---|---|
  | 인식 없음 | 6/48 |
  | 시뮬레이터 앞차 정보 사용 | 3/48 |
  | 속도 15 km/h 제한 | 6/48 |
  | v1.6을 새 환경에서 | 23/48 (환경은 정상) |

- 수정: `CAB_EYE_X = 4.1`. 5개 화면 × 3개 회전각 모두 렌더링해 차체가 없음을 확인했습니다.

### 4-2. "서 있으면 정지" 지름길 (v1.8d 멈춤)
- 신호 없는 빈 도로에서도 정지 확률 1.00, 정지선 7 m로 판단해 출발하지 못했습니다(Town01 seed 200의 1·4·8번 경로).
- 같은 이미지에 속도 입력만 바꾸면, 0~7 km/h에서 1.00, 18 km/h에서 0.83~1.00이 나왔습니다.
- 원인 추정: 학습 데이터에서 서 있는 장면은 거의 다 빨간불 앞이었습니다.
- 수정: `RouteSteeringNet(percept_from_image=True)`. 인식 4개 출력을 이미지 특징만으로 만들고, 속도와 명령은 넣지 않습니다. 이 수정이 v1.8e입니다.
- 아직 안 한 보강: 서 있는데 신호가 없는 장면을 데이터에 섞기(재수집 필요).

### 4-3. 2단계 전문가 검증
- 처음에는 정지 구간 6 m 안에서 멈추지 못해 Town03에서 8번 중 7번 막혔습니다. IDM이 표지판 약 7 m 앞에서 멈추기 때문입니다.

## 5. 확정된 결정 (사용자 확인)
- 규칙을 모델 판단으로 바꾸는 작업 범위:
  - 1단계(신호등·앞차)와 2단계(정지 표지판·양보)까지 진행합니다.
  - 3단계(속도 표지판·장애물 회피·차로 변경)는 하지 않습니다.
- 속도 조절도 학습으로 합니다(v1.7부터). 땜질이 아니라 근본 해결을 원칙으로 합니다.
- 카메라는 ETS2 운전석 위치에 맞춥니다.
  - CARLA 시야각은 120°로 유지하고, 나중에 ETS2 시야각을 넓혀 맞춥니다.
  - 해상도는 160×320입니다.
- ETS2로 옮기는 건 CARLA에서 기본 주행이 될 때 합니다. 제안 기준은 48개 중 약 80% 완주이며, 숫자는 아직 사용자 미확정입니다.
- 비싼 작업 전에 짧은 확인을 하되, 할 때는 확실하게 합니다.
  - 수집 전: 모든 화면 × 회전각을 렌더링해 확인합니다.
  - 학습 후: 지름길 검사를 합니다(속도만 바꾸기, 빈 도로, 화면 가리기).
  - 전체 평가 전: 경로 6개로 짧게 달려 봅니다.
  - 합격 기준은 먼저 숫자로 정하고, 확인한 것과 못 한 것을 함께 보고합니다.
- 속도는 사용자에게 km/h로 말합니다.

### 8-2. 설치 절차
데스크탑 환경: CARLA 0.9.16, Python 3.12.10, torch 2.14.1+cu132, torchvision 0.29.1+cu132, numpy 2.5.4, Pillow 13.0.0, pytest 9.1.1.

1. **Python 3.12 설치.** CARLA 파이썬 API가 3.12까지 지원합니다. 기본 Python은 그대로 두고 나란히 설치합니다.
2. **CARLA 0.9.16 Windows 패키지.** 공식 릴리스에서 받아 압축을 풉니다(약 20 GB). 예: `D:\CARLA\CARLA_0.9.16`. 경로가 다르면 명령의 `--carla-root`를 바꿉니다.
3. **가상환경.** 저장소 폴더에서:
   ```
   py -3.12 -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt carla==0.9.16 networkx
   ```
4. **CUDA용 torch·torchvision.**
   - RTX 5060(Blackwell)은 CUDA 12.8 이상용 빌드가 필요합니다. 일반 `pip install torch`로는 GPU를 못 씁니다.
   - pytorch.org에서 cu128 이상 인덱스 명령을 확인해 설치합니다. 데스크탑은 cu132 인덱스를 씁니다.
   - 확인: `.venv\Scripts\python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"`
5. **테스트.** `.venv\Scripts\python -m pytest -q`. 데스크탑 기준 145개 통과, 1개 건너뜀입니다.
6. **CARLA 서버 확인.**
   ```
   CarlaUE4.exe -carla-rpc-port=2000 -RenderOffScreen
   ```
   잠시 뒤 확인:
   ```
   .venv\Scripts\python -c "import carla; c=carla.Client('localhost',2000); c.set_timeout(10); print(c.get_server_version())"
   ```
