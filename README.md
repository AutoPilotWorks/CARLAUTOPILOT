# CARLAUTOPILOT — CARLA 기반 영상 자율주행 연구

## ETS2 프로젝트에서 이어받는 것
이전 프로젝트 [ets2-autopilot-learning](https://github.com/AutoPilotWorks/ets2-autopilot-learning)(비공개, 소유자만 접근 가능)에서 얻은 것을 **그 저장소의 2026-10-19 인계 문서 기준으로 요약**한 것입니다. 이 저장소에서 다시 검증하지 않았습니다.
- **목표 철학(사용자, 2026-10-19 ETS2 문서):** 화면만 보고 AI가 스스로 판단하는 자율주행을 만든다. 따라 하기와 규칙 덧대기로 끝내지 않고, 규칙은 하나씩 걷어내며 "모델만"으로 매번 측정한다. ACC처럼 실제 차를 흉내 낸 공학 모듈은 섞어도 되지만, 따로 떼어 나중에 학습으로 바꿀 수 있게 만든다.
- **실패에서 배운 것:** 10월 14일 벽 충돌의 원인은 모델이 아니라 **차선 보조 규칙**이 엉뚱한 선을 잡아 모델의 조향을 뒤집은 것이었다. 규칙을 넣으면 그 규칙이 오류의 원인이 될 수 있다.
- **평가에서 배운 것:** 라벨 정의가 겹치면(감속과 정지) 모델 한계처럼 보이는 오류가 생긴다. 세션 단위 교차검증과 단순한 기준선(속도만 쓰는 결정트리)과의 비교가 필요하다. 신호등을 학습으로 바꾼 시도는 손으로 만든 색 규칙보다 성능이 낮았다(0.71 대 0.78).
- **데이터:** 사용자가 직접 녹화하지 않고, CARLA에서는 기본 자동 주행으로 자동 수집하는 방식을 시험할 계획이다(미확인).
- ETS2 프로젝트에서 쓸 만한 코드(ACC, 안전 계층, 평가 도구 등)는 필요할 때 골라서 가져온다.

## 컴퓨터와 위치
- **실행:** 집 데스크톱(RTX 4070 SUPER 12GB). 원격 접속은 아직 설정되어 있지 않습니다.
- **코드 작성:** GPU가 필요 없는 작업은 다른 컴퓨터에서도 합니다. CARLA를 실행하는 시험은 데스크톱에서만 가능합니다.
- 코드의 경로는 컴퓨터마다 다르므로 데이터 루트 등은 인자나 설정으로 받습니다. 데이터, 학습 결과, CARLA 설치 파일은 이 저장소 밖에 둡니다.
- 이 저장소를 만든 컴퓨터(GPU 없음)는 2026-10-21 저녁에 포맷할 예정이었습니다(완료 여부는 이 문서를 쓸 때 확인하지 못했습니다). 그 컴퓨터의 백업(취업 계획 파일, 실습 폴더, Claude 메모리, 대화 기록)은 USB의 `pre-format-backup-2026-10-21` 폴더에 있습니다.

## 환경 (계획)
- CARLA 0.9.15, Python 3.12(CARLA Python API는 3.12까지 지원). 공식 문서 기준 VRAM 8GB 이상 권장, 디스크 약 20GB, 포트 2000과 2001.
- 이전 컴퓨터의 Python은 3.14였으므로 CARLA용 3.12 가상환경을 따로 만들어야 합니다.
