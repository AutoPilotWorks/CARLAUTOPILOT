# CARLAUTOPILOT — CARLA 기반 영상 자율주행 연구

CARLA 시뮬레이터에서 **영상으로 판단하는 자율주행**을 만들고, 거의 모든 기능이 동작한다고 판단되면 Euro Truck Simulator 2(ETS2)로 옮기는 프로젝트입니다. 최종 목표는 화물을 배달하는 경로를 처음부터 끝까지 스스로 주행하는 것입니다.

## 현재 상태 (2026-10-21 저녁, 집 데스크톱)
- **CARLA 0.9.16 + Python 3.12 환경을 설치했고 CARLA 어댑터(`carlautopilot/carla_env/`)를 만들었습니다.** 경로 계획(CARLA `GlobalRoutePlanner`), 다른 차량(Traffic Manager), 신호등, 충돌 판정, 보조 카메라까지 동작합니다. 세부 사실은 [docs/architecture.md](docs/architecture.md)의 "CARLA 어댑터" 절.
- **전문가(정답 정보를 쓰는 규칙 운전자, 학습 라벨용):** 회전 감속을 넣은 뒤 Town01 7/8, Town03 8/8 완주. 처음 보는 Town02는 7/10(고정물 충돌 2, 시간 초과 1). 정답 정보를 쓰므로 "자율주행 성능"이 아닙니다.
- **영상 모델(카메라만 보고 조향, 속도는 ACC 규칙):** 아직 **거의 운전하지 못합니다.** 작은 CNN은 완주 0, 경로 진행률 13~24%. 사전학습 ResNet18로 바꾸자 Town03 30%, 처음 보는 Town02 43%에 완주 1/10이 처음 나왔습니다(전문가는 8/8, 7/10). 보조 카메라를 넓힌 데이터를 더해(80개) 학습한 C는 B와 비슷했고, 평가 쪽 문제 두 가지(회전 속도 불일치, 차로 변경이 든 경로)를 고친 뒤 **Town03 35%(완주 2/8), Town02 55%(완주 3/10)**가 됐습니다. 남은 실패는 대부분 좌회전입니다. 조향만 학습이고, 속도는 ACC와 교차로 감속 **규칙**입니다. 모델 비교 표는 docs/plan.md.
- 페달까지 모델이 내게 하면 10개 모두 출발하지 못했습니다(브레이크 라벨 0.4%, 정지 상태를 따라 하는 문제로 추정).
- 자동 테스트 133개 통과, 1개 건너뜀(CUDA가 있으면 건너뛰는 테스트), Python 3.12 + CUDA torch.

## 코드를 돌려 보는 법
```bash
python -m pytest -q
python -m carlautopilot.cli.evaluate --out-dir <새 폴더> --title "Baseline"
```
CARLA 서버(`CarlaUE4.exe`)를 켠 뒤:
```bash
python -m carlautopilot.cli.carla_run collect --carla-root <CARLA 폴더> --town Town03_Opt --episodes 10 --data-root <데이터 폴더> --stride 4 --views "1:0,-1:0,0:10,0:-10"
python -m carlautopilot.train.train_steering --data-root <데이터 폴더> --out-dir <학습 폴더> --device cuda --num-workers 6
python -m carlautopilot.cli.carla_run eval --carla-root <CARLA 폴더> --town Town02_Opt --episodes 10 --seed 100 --checkpoint <학습 폴더>/checkpoint.pt --out-dir <평가 폴더>
```
- `eval`에 `--checkpoint`가 없으면 전문가를 평가합니다. 한 번에 도시 하나만 다룹니다(맵 전환은 별도 프로세스, 이유는 architecture.md).
- 설치: Python 3.12 가상환경에 `requirements.txt`, CUDA용 `torch`·`torchvision`(pytorch.org의 cu132 인덱스), `carla==0.9.16`, `networkx`.

## 다음 할 일 (모두 사용자 승인 후)
1. **고친 전문가(짧은 시선)로 차로 변경 없는 데이터를 다시 수집하고 재학습.** 차로 변경 없는 데이터로 학습한 D(Town03 20%, Town02 51%)가 C보다 나아지지 않았고, 원인은 전문가가 회전 모서리를 잘라 먹은 것이었다(docs/plan.md). 아래는 2026-10-22에 쓴 계획(①은 실행했고 48/80이 차로 변경이었음).
   - (이전 계획) 차로 변경 없는 데이터로 재학습. 지금 데이터(`carla_v2` 80개)에는 차로 변경 경로가 섞여 있다. 순서(사용자와 정한 계획, 시간은 2026-10-21 실측 기준 추정):
   - ① 저장된 `scenarios/*.json`의 출발점·도착점으로 `GlobalRoutePlanner`를 다시 돌려 차로 변경이 있던 에피소드를 찾아 빼고 ResNet18 재학습(약 1시간 20분). 같은 입력에 같은 경로가 나오는지 먼저 확인할 것(미확인).
   - ② 빠진 게 많으면 새로 40개 수집(약 1시간 20분) 후 학습(약 30분).
   - ③ C와 같은 규모(80개) 새로 수집이면 약 3시간 50분.
   - 그다음 좌회전 실패 분석, 평가 경로 늘리기(차이가 우연인지 가리기).
2. 속도도 모델이 정하게 하기(지금은 ACC + 교차로 감속 규칙). 신호 정지도 모델로.
3. 입력 개선(해상도, 이전 프레임 함께 보기), 다른 폴드로 재현성 확인.
4. 그래픽 품질은 Epic 유지(사용자, 2026-10-21: 컴퓨터에 문제가 없으면 Epic). 트럭(`vehicle.carlamotors.european_hgv` 등)은 세단으로 방법이 통한 뒤 옵션으로 추가.
4. 통과 기준 수치 정하기(plan.md "아직 확정되지 않은 것").

## ETS2 프로젝트에서 이어받는 것
이전 프로젝트 [ets2-autopilot-learning](https://github.com/AutoPilotWorks/ets2-autopilot-learning)(비공개, 소유자만 접근 가능)에서 얻은 것을 **그 저장소의 2026-10-19 인계 문서 기준으로 요약**한 것입니다. 이 저장소에서 다시 검증하지 않았습니다.
- **목표 철학(사용자, 2026-10-19 ETS2 문서):** 화면만 보고 AI가 스스로 판단하는 자율주행을 만든다. 따라 하기와 규칙 덧대기로 끝내지 않고, 규칙은 하나씩 걷어내며 "모델만"으로 매번 측정한다. ACC처럼 실제 차를 흉내 낸 공학 모듈은 섞어도 되지만, 따로 떼어 나중에 학습으로 바꿀 수 있게 만든다.
- **실패에서 배운 것:** 10월 14일 벽 충돌의 원인은 모델이 아니라 **차선 보조 규칙**이 엉뚱한 선을 잡아 모델의 조향을 뒤집은 것이었다. 규칙을 넣으면 그 규칙이 오류의 원인이 될 수 있다.
- **평가에서 배운 것:** 라벨 정의가 겹치면(감속과 정지) 모델 한계처럼 보이는 오류가 생긴다. 세션 단위 교차검증과 단순한 기준선(속도만 쓰는 결정트리)과의 비교가 필요하다. 신호등을 학습으로 바꾼 시도는 손으로 만든 색 규칙보다 성능이 낮았다(0.71 대 0.78).
- **데이터:** 사용자가 직접 녹화하지 않고, CARLA에서는 기본 자동 주행으로 자동 수집하는 방식을 시험할 계획이다(미확인).
- ETS2 프로젝트에서 쓸 만한 코드(ACC, 안전 계층, 평가 도구 등)는 필요할 때 골라서 가져온다.

## 컴퓨터와 위치
- **실행:** 집 데스크톱(RTX 4070 SUPER 12GB). 원격 접속은 아직 설정되어 있지 않습니다.
- **코드 작성:** GPU가 필요 없는 작업은 다른 컴퓨터에서도 합니다. CARLA를 실행하는 시험은 데스크톱에서만 가능합니다.
- 코드의 경로는 컴퓨터마다 다르므로 데이터 루트 등은 인자나 설정으로 받습니다. 데이터, 학습 결과, CARLA 설치 파일은 이 저장소 밖에 둡니다.
- 이 저장소를 만든 컴퓨터(GPU 없음)는 2026-10-21 저녁에 포맷할 예정이었습니다(완료 여부는 이 문서를 쓸 때 확인하지 못했습니다). 그 컴퓨터의 백업(취업 계획 파일, 실습 폴더, Claude 메모리, 대화 기록)은 USB의 `pre-format-backup-2026-10-21` 폴더에 있습니다.
